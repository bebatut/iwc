# Metagenomic Read-Based Functional Profiling

This workflow **profile the functional potential of metagenomic datasets** using **HUMAnN** to generate gene- and pathway-level functional profiles, including Gene Ontologies (GO). This workflow is designed for **quality-controlled, host/contaminant-free metagenomic short-read data**.

## **Inputs**

- Paired collection **FastQ files** with metagenomic short-read data (post-QC and host/contaminant removal)
- *(Optional)* **Taxonomic profile** generated by MetaPhlAn (if available)
- **Reference databases** required for HUMAnN functional profiling

## **Workflow Overview**

1. **Functional Profiling with HUMAnN**
   - **Tiered search strategy**:
     - Taxonomic prescreen (skipped if a taxonomic profile is provided)
     - Pangenome search
     - Translated search
  - **Outputs**:
    - Per-species and community-level gene-family abundances
    - Metabolic pathway abundance profiles

2. **Output Formatting**
   - **Normalization** of HUMAnN abudance outputs with all levels scaled by community total for relative abundances
   - **Metabolic pathway unpacking** to include involved genes
   - **Gene Ontology (GO) mapping**

3. **Aggregation & Reporting** via **MultiQC** for cross-sample and cross-tool comparisons


## **Outputs**

- **Gene family abundance**, original and normalized profiles
- **Metabolic pathway abundance**, original, normalized, and gene-mapped
- **Metabolic pathway coverage** with metrics for pathway completeness
- **Gene Ontologies (GO)**
- **MultiQC HTML report**
