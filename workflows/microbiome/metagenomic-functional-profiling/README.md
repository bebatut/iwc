# Metagenomic Functional Profiling Workflow

This Galaxy workflow performs functional profiling of shotgun metagenomic data using HUMAnN.  
It generates gene family and pathway-level functional profiles, optionally stratified by taxonomic composition.

The workflow is designed for quality-controlled metagenomic sequencing data and integrates taxonomic profiles generated by MetaPhlAn.

---

## **Inputs**
- Quality-controlled paired-end FASTQ files
- (Optional) Host-depleted reads  
  *Required only for host-associated samples*
- MetaPhlAn taxonomic profile

---

## **Outputs**
- Gene family abundance tables
- Pathway abundance tables
- Pathway coverage tables

---

## **Use Cases**
- Functional characterization of gut, oral, skin, or environmental metagenomes
- Comparative functional profiling across samples or groups
- Downstream statistical or pathway enrichment analysis  

---

## **Workflow Steps**
- Performs taxonomy-informed functional profiling using HUMAnN
- Maps reads to nucleotide reference databases guided by MetaPhlAn taxonomic profiles
- Assigns functions to unmapped reads using translated protein searches
- Produces gene family and pathway-level functional profiles, including taxon-stratified outputs
